# 数据集说明

## 数据来源（真实公开数据，非模拟）

- **数据集**：CN-AIR —— China Air Quality Historical Dataset
- **整理来源**：中国环境监测总站（CNEMC）公开监测数据
- **许可**：MIT（仓库：https://gitcode.com/GewisLab/CN-AIR ）
- **本项目使用范围**：2024 全年，375 个城市，逐日 6 项污染物 + AQI
- **记录数**：137,250 行（375 城 × 366 天， leap year）

## 原始数据形态

小时级「日宽表」：每个自然日一个 CSV（`china_cities_YYYYMMDD.csv`），
结构为 `date, hour, type, 城市1 ... 城市375`，type 共 15 种
（AQI / PM2.5 / PM2.5_24h / PM10 / PM10_24h / SO2 / SO2_24h / NO2 /
NO2_24h / O3 / O3_8h / O3_24h / O3_8h_24h / CO / CO_24h）。

获取方式：`python scripts/fetch_data.py --year 2024`
（git 稀疏检出 + Git LFS，只下载指定年份，约 135MB）。

## 分析用数据（data/processed/air_quality_2024.csv）

由 `scripts/prepare_data.py` 分片转换生成的 tidy 长表，一行 = 一城一天：

| 列 | 含义 |
|---|---|
| 城市 | 监测城市（375 个） |
| 日期 | 2024-01-01 ~ 2024-12-31 |
| AQI | 空气质量指数（当日最后发布值） |
| 质量等级 | 由 AQI 按 HJ 633-2012 推导：优/良/轻度/中度/重度/严重污染 |
| PM2.5 / PM10 / SO2 / NO2 / CO / O3 | 当日小时均值（浓度；CO 为 mg/m³，其余 μg/m³） |
| PM2.5_24h 等 _24h 系列 | 当日 24h 平均（滚动序列末日发布值） |
| O3_8h | 日最大 8 小时平均（GB 3095 臭氧判定口径） |

## 日值口径说明

1. `_24h` 系列取当日最后一个非空小时值（滚动 24h 序列的末日发布值），
   全空时回退为小时浓度当日均值；
2. `O3_8h` 取当日各小时 8h 滑动平均的最大值，即「日最大 8 小时平均」；
3. `AQI` 取当日最后非空小时值，质量等级按 HJ 633-2012 断点推导；
4. 缺失率约 8.8%，主要为年内新接入站点城市；分析时按有效值计算并记录缺失率。

## 数据自检样例（2024，可用于答辩佐证）

- 北京 PM2.5 年均 31.4 μg/m³，有效天数 366；
- 北京夏季（6-8 月）O₃ 日最大 8h 平均超标 45/92 天（限值 160 μg/m³）；
- 全国 PM2.5 年均 TOP5：和田地区 88.2、喀什地区 56.5、安阳 50.9、
  鹤壁 50.4、克孜勒苏柯尔克孜自治州 50.0 μg/m³；
- 各省份 PM2.5 超标天数占全国比例 TOP3：河南 14.0%、新疆 10.0%、四川 6.6%。
